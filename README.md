# ロボット研究所：オブジェクト指向チェックテスト

中高生向け／目安 30〜45 分／Swift の変数・関数・if 文を学習済みの人向け。

これは**意図的に未完成の教材**です。配布時点でもビルドできる構成ですが、正しい名前やあいさつが出ず、充電・お仕事・チーム表示が機能しません。バグではなく、解答するための空欄です。

## 開き方

1. Mac の Xcode で `RobotOOPCheck.xcodeproj` を開きます（Xcode 15 以降、iOS 17 以降）。
2. 実行先に iPhone シミュレータを選び、▶︎（Command + R）で起動します。外部ライブラリやアカウント設定は不要です。
3. `問題.md` を読み、`RobotOOPCheck/Robot.swift` の TODO 1〜5 を編集します。
4. 修正後にもう一度実行し、動きを確認します。初期状態を確認するときはアプリを終了して再実行してください。

実機で使う場合は Signing & Capabilities で自分の Team と一意な Bundle Identifier を設定してください。

## ファイル案内

- `問題.md`：問題・操作での確認方法・記述問題
- `RobotOOPCheck/Robot.swift`：生徒が編集する未完成コード
- `RobotOOPCheck/ContentView.swift`：完成済みの画面
- `Teacher/`：教員専用の解答例と採点基準。**生徒への配布前にこのフォルダを取り除いてください。**
- `Checks/`：任意の自動チェック。アプリには組み込まれません。

`ObservableObject` と `@Published` は状態の変化を画面へ知らせ、`@StateObject` は画面が使うオブジェクトを保持する仕組みです。このテストでは変更不要です。画面の `struct` と、今回学習する `class` は区別しましょう。

## 任意の自動チェック

ターミナルでこのフォルダに移動し、`bash Checks/check.sh` を実行します。未完成版では FAIL が出て終了コードが 1 になります。全問完成するとすべて PASS になります。Mac の Swift コンパイラが必要です。
